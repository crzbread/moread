# MoRead

在 terminal 裡選一本書，多讀一點。

MoRead 是一個終端書櫃與 EPUB 閱讀器。瀏覽自己的資料夾、搜尋書名或作者，並從上次的位置繼續閱讀。書櫃根目錄的「最近閱讀」會集中顯示各資料夾中讀過的書。

## 開始使用

需要 Python 3.11 以上和支援 UTF-8 的終端，建議視窗至少 40 欄、18 列。

```sh
uv sync
uv run moread
```

預設書庫是 `~/Documents/Books`。可以按 `F2` 修改，也可以啟動時指定：

```sh
uv run moread --library /path/to/Books
```

不使用 uv 時，可在虛擬環境執行 `python -m pip install .`，再執行 `moread`。

## 操作方式

| 書櫃 | 按鍵 |
| --- | --- |
| 選擇項目 | ↑ / ↓ |
| 進入資料夾 | → |
| 開啟資料夾或書籍 | Enter |
| 返回上層 | ← / Backspace |
| 搜尋 | `/` |
| 重新整理 | F5 |
| 設定 | F2 |

搜尋書名、作者或資料夾名稱時，可以混用繁體與簡體中文。一般資料夾只搜尋目前層級；「最近閱讀」則搜尋其清單。

| 閱讀 | 按鍵 |
| --- | --- |
| 翻頁 | ← / → |
| 移動一行 | ↑ / ↓ |
| 切換章節 | `n` / `p` |
| 章節目錄 | `t` |
| 返回書櫃 | Esc / Backspace / `b` |
| 設定 | F2 |

`q` 離開程式，`Ctrl+D` 可從任何畫面立即離開。輸入框內可正常輸入 `q`。

## 設定與閱讀進度

按 `F2` 可調整書庫位置、閱讀寬度、主題、空白鍵動作及立即離開鍵。設定畫面使用 `Ctrl+S` 儲存、Esc 取消；若立即離開鍵設為 `Ctrl+S`，請用 Tab 選取儲存按鈕後按 Enter。

設定和進度儲存在使用者目錄，macOS 預設位於 `~/Library/Application Support/dbb-reader/`。書籍本身不會被修改。書籍移動或改名後會被視為新書；同時執行多個 MoRead 實例時，進度不會自動合併。

## 目前限制

閱讀器仍屬實驗性功能。支援 EPUB 文字閱讀與續讀；PDF、圖片、DRM、直排及複雜排版尚不支援。PDF 會顯示在書櫃中，但無法開啟。
